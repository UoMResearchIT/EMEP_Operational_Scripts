# EMEP_Operational_Scripts

Collection of scripts, and namelists, for running EMEP (and WRF) on CSF3

Many of the scripts here are prototypes, which have been superceded by scripts in other repositories. They are preserved for reference here.

There is not a central dependency library for this collection, as some scripts are python, others NCL, etc. Instead each script will have an environment dependency file with it (where that script has been updated recently).
